# 🦈 KRAKEN v3.0

**Motor de Explotación Autónomo con IA, Automatización y Despliegue en Producción**

KRAKEN es un sistema avanzado de **seguridad ofensiva** diseñado para:
- Escanear redes en busca de vulnerabilidades
- Explotar automáticamente vulnerabilidades conocidas
- Aprender de cada interacción para priorizar objetivos
- Integrarse con sistemas de inteligencia de amenazas
- Automatizar respuestas a incidentes
- Generar informes profesionales

---

## 🚀 Características Principales

| **Categoría**          | **Características** |
|------------------------|---------------------|
| **Escaneo**           | Nmap + Masscan, escaneo paralelo, detección de OS/servicios/CVEs |
| **Explotación**       | 15+ módulos de explotación (SSH, FTP, SMB, HTTP, RDP, etc.) |
| **Base de Datos**     | SQLite/PostgreSQL con ORM (SQLAlchemy), cifrado opcional |
| **Aprendizaje**       | Sistema de priorización por CVSS, detección de anomalías con IA |
| **Automatización**     | Bloqueo de IPs, integración con SIEM, notificaciones en tiempo real |
| **Integraciones**     | Shodan, Censys, VirusTotal, Telegram, Slack, Email, Webhooks |
| **API**               | FastAPI (REST + WebSocket) con autenticación |
| **Dashboard**         | Streamlit + React con gráficos en tiempo real |
| **Informes**          | Generación de informes en PDF/HTML/JSON |
| **Despliegue**        | Docker, Kubernetes, systemd |
| **CLI**               | Interfaz de línea de comandos con Click |
